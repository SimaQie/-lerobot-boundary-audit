208 项是少量样例的读取组合，包含人工故障应当失败的情形；不是 208 个独立真实缺陷。
真实视频中邻近画面完全相同时，帧身份不能唯一确定，因此明确保留 PARTIAL 结果。
顺序解码参考也不能证明采集前的帧身份、原始相机标记或物理同步。

同输入比较实际运行了固定提交的 lerobot-doctor 和 openbot-data，保留原始告警。
两者均对索引问题提供信息，独立画面编号不是通用索引检查的替代。
相机交换、重复帧和帧顺序交换的画面身份错误，在本基准中由独立身份验证明确发现。
OpenBot 对官方样例的单维特征与标量存储形状有更严格的检查；本项目的干净控制仅
指已声明的读取和数值预期，不证明该规则是误报，也不证明满足所有训练策略的张量形状。
